# Federico Bocol III — Portfolio Website

This is a responsive, single-page portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — all seven portfolio sections
- `style.css` — responsive layout, colors, typography, and animations
- `script.js` — mobile navigation, portfolio filters, reveal effects, and email-form behavior

## Before publishing
1. Keep a backup of your current GitHub repository.
2. Copy these three files into the root of your existing repository, replacing `index.html`, `style.css`, and `script.js` only after reviewing the backup.
3. Keep your existing `assets` folder.
4. Add your real portrait at `assets/federico-portrait.jpg`.
5. Check the sample asset names in `index.html`. Existing media used by the current project include:
   - `assets/ram3500.png` (the page also tries `assets/ram-3500.png` as a fallback)
   - `assets/banana_chips.mp4`
   - `assets/products.mp4`
6. Add screenshots/certificates from your own work before replacing the sample placeholders. Do not label practice/training work as paid client work.

## Contact form
The form uses a `mailto:` link. It opens the visitor's email application with the message prepared; it does not submit to a server. A backend or form service is required for silent website form submission.

## GitHub Pages
In your repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Wait for GitHub Pages to publish the site.
